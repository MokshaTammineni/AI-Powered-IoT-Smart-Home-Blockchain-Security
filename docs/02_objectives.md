# Project Objectives

## Primary Objectives
1.  **To Implement Vision-Based IoT Sensing**: Convert a standard webcam into an intelligent IoT sensor capable of detecting motion and capturing inputs for the system, demonstrating "Edge Computing" principles.
2.  **To Deploy AI-Driven Authentication**: Develop a facial recognition system that accurately classifies individuals as "Authorized" or "Intruders" in real-time, reducing false alarms associated with traditional sensors.
3.  **To Ensure Log Immutability via Blockchain**: Design and implement a custom Python-based blockchain to store security events (entry logs, intrusion alerts), ensuring that records are tamper-proof and cryptographically linked.
4.  **To Create a Real-Time Decision & Alert System**: Integrate the AI and Blockchain modules into a cohesive system that triggers instant visual/text alerts upon detecting unauthorized access.
5.  **To Develop a User-Friendly Dashboard**: Build a Flask-based web interface to visualize the live video feed, security status, and the immutable blockchain ledger.

## Scope of Work
- **Included**: Webcam simulation, Face Recognition (local dataset), Python Blockchain implementation, Flask Web UI.
- **Excluded**: Physical sensors (PIR/IR), Hardware microcontrollers (Arduino/Pi), Decentralized P2P network (single node simulation for demonstration).
